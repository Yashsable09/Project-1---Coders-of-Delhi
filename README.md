# Project-1---Coders-of-Delhi
A Data Science project focused on cleaning and analyzing social-network data to find “People You May Know” and “Pages You Might Like” using Python and Pandas.



Project 1 - Coders of Delhi

A Data Science project based on the CodeBook / Coders of Delhi
dataset. The project focuses on cleaning and structuring social-network
data and using it to discover meaningful connections and
recommendations.

📌 Project Overview

In this project, we work with data related to people and pages on a
social-network-style platform. The main goal is to transform raw data
into a clean, structured format and use data analysis techniques to
identify useful relationships.

Key Tasks

Clean and preprocess the raw dataset

Structure the data for analysis

Find People You May Know

Find Pages You Might Like

Explore relationships and common interests in the data

Apply Python-based data analysis techniques

🔍 Project Modules

1. Cleaning and Structuring the Data

The raw data is inspected, cleaned, and converted into a structured
format suitable for analysis.

Typical operations include:

Handling missing or inconsistent values

Converting data into usable structures

Extracting relevant information

Preparing data for recommendation analysis

2. Finding "People You May Know"

This module analyzes available connections and relationships to identify
potential people who may be relevant to a user.

The recommendation can be based on relationships such as:

Mutual connections

Shared network patterns

Common attributes in the dataset

3. Finding "Pages You Might Like"

This module analyzes user-page relationships to identify pages that may
be relevant to users based on available interaction or connection data.
